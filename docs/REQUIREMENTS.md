# 本地 UI 组件资源库需求文档

版本：0.1.0  
日期：2026-10-22  
项目根目录：`C:\E\ui`

## 1. 项目目标

在 Windows 本机建立一个仅复刻 Uiverse `/elements` 浏览体验的本地 UI 组件资源库。用户可以浏览本地收集的 UI、查看真实运行效果、搜索和分类筛选、查看源码、复制源码并下载组件目录。

本项目不制作 Uiverse 首页，不包含首页 Hero、社区统计、博客或 Discord 区块。

本阶段暂不接入 Ollama、向量数据库和向量化；同时完成无模型版本地知识库检索能力、MCP Server 和可移植 Skill。所有检索使用本地元数据、关键词和源码全文。

## 2. 目录约定

| 目录 | 用途 | 修改规则 |
|---|---|---|
| `C:\E\ui\library` | 原始 UI 素材库 | 只读，禁止修改、移动、删除 |
| `C:\E\ui\src` | 网站前端源码 | 可修改 |
| `C:\E\ui\data` | 自动生成的索引 | 可重新生成 |
| `C:\E\ui\previews` | 后续可生成的预览资源 | 可重新生成 |
| `C:\E\ui\logs` | 扫描日志 | 可追加或重新生成 |

## 4. 功能需求

### 4.1 Elements 入口页面

- 深色背景和卡片式布局。
- 顶部分类导航。
- UI 组件网格展示。
- 每张卡片显示真实组件预览。
- 显示组件名称、分类、技术类型和标签。
- 支持搜索组件名称、分类、标签和来源路径。
- 支持分类筛选。
- 支持独立标签筛选。
- 支持名称和分类排序。
- 显示当前索引组件数量。

### 4.2 扫描 UI 库

- 页面提供“扫描 UI 库”按钮。
- 扫描根目录固定为 `C:\E\ui\library`。
- 扫描必须是手动触发，不在每次启动时强制扫描。
- 支持 HTML、CSS、JS、Vue、React、JSX、TSX、Tailwind、SVG 和图片等实际存在的文件。
- 优先识别 `preview.html`、`index.html`、`demo.html`、`fullscreen.html` 作为预览入口。
- 没有标准入口时，允许将单个 HTML 文件作为组件入口。
- 根据目录名、文件名、扩展名和路径自动推断名称、分类、标签、来源和技术类型。
- 不能识别的文件只记录错误，不得中断整个扫描。
- 扫描结果写入本地索引，不修改原始素材。
- 重复扫描需要支持新增、修改和删除检测。

### 4.3 详情查看

- 点击卡片打开详情弹窗或详情页。
- 显示实时预览。
- 显示来源路径、分类、技术类型和关联文件。
- 支持切换关联源码文件。
- 支持复制当前源码。
- 支持下载组件目录。

### 4.4 预览要求

- 预览区域使用 iframe 隔离。
- 允许组件中的 HTML、CSS 和 JavaScript 运行，以保持真实效果。
- 预览不能遮挡源码和操作区域。
- 预览路径必须限制在 `C:\E\ui\library` 内，禁止路径穿越和任意文件读取。

## 5. 第一阶段验收标准

- 可以通过本地地址启动网站。
- 可以读取并展示扫描索引。
- 可以看到 UI 卡片网格和真实预览。
- 可以按分类和搜索条件筛选。
- 可以打开详情。
- 可以查看和复制源码。
- 可以下载组件目录。
- 点击扫描按钮后可以重新生成索引。
- 原始 `library` 文件内容和路径没有被修改。

## 6. MCP 与 Skill（无模型阶段）

- MCP 默认通过 stdio 运行，也支持本地 Streamable HTTP 风格的 JSON `/mcp` 端点。
- 提供扫描、状态、元数据搜索、源码全文搜索、源码读取、预览信息和词法相似推荐工具。
- Skill 文件位于 `C:\E\ui\skills\local-ui-library\SKILL.md`，不修改原始 UI 素材。
- 当前不安装或调用 Ollama；`vectorSearch` 和 `ollama` 能力明确返回 `false`。
